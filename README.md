Project: Red Box (v1.0)
Welcome to the development hub for an immersive, old-school RPG experience. This project transitions from a basic scaffold into a tactile, "Trapper Keeper" style adventure inspired by the legendary Module B1: In Search of the Unknown.

Overview
This project focuses on the "Threshold to B1" loop, taking players from a basic tutorial into a fully realized mechanical ecosystem. The gameplay is centered around a persistent Tactical Folder UI, designed to mimic the feel of weathered paper and physical tabletop materials.

Core Features
Tactile Folder Interface: A 5-tab system featuring a character sheet, weight-based inventory, automated journal, 10' square graph paper maps with Fog of War, and a THAC0 reference guide.

The Town of Threshold: A non-combat hub where players can rest at the Gold Dragon Inn, gear up at the Shop, and gather rumors about the legends of Rogahn the Fearless and Zelligar the Unknown.

Module B1 Integration: Exploration of the Caverns of Quasqueton, featuring room-based logic, secret door mechanics, and a bestiary including Orcs, Troglodytes, and Giant Rats.

Persistent Progression: Full campaign systems supporting Level 1-10 XP curves and local storage save states for all town and dungeon progress.

Development Roadmap
Sprint 1: Establishing the Structural Foundation and the Folder Shell UI.

Sprint 2: Building the Town of Threshold and NPC interaction systems.

Sprint 3: Implementing the "Dungeon Engine" for Quasqueton and mystery mechanics.

Sprint 4: Finalizing Campaign Systems, soundscapes, and E2E testing for public launch.
